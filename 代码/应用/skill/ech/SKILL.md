# ech

回响（Mac 应用）带的命令行工具，跟着回响一起装、一起升级。装在 `~/.local/bin/ech`；运行时提示找不到 `ech`（这个目录不在 PATH 里），就用完整路径 `~/.local/bin/ech`，不用去改 shell 配置。查询命令只读备份和本机索引；`ech backup` 写备份，和回响的「立即备份」一样；`ech mv` 改名或移动文件夹并移动会话，和回响左栏目录右键「改名」一样。

## 用哪条命令

| 要做的事 | 命令 |
|---|---|
| 找以前会话里说过的话、定过的事 | `ech find <关键词>`，再 `ech read <引用>` |
| 看一个会话分了哪几段 | `ech segs <会话>` |
| 接着另一个会话（或另一台电脑上的会话）做 | `ech context <会话>` |
| 要某个会话的恢复命令（到终端或 MintPop 主页里打开原会话） | `ech resume <会话>` |
| 列一段时间的会话和提交（周报） | `ech list --since 2026-11-16 --until 2026-11-22` |
| 要查今天刚聊过的内容 | 先 `ech backup` |
| 改名或移动文件夹（里面开过会话的也一样） | `ech mv <旧路径> <新路径>`，不用 `mv` |

## 命令

```bash
# 按关键词找，几个词用空格分开、都要有；结果按会话分组，每处带一个引用（会话#段号）
ech find "主色 定 B"
# 只找 Codex 的、11-16 以后的、项目路径里有「回响」的
ech find 分段 --app codex --since 2026-11-16 --project 回响
# 读第 21 段
ech read ce57ce36#21
# 读第 1200 到 1500 行
ech read ce57ce36#L1200-1500
# 只写会话：读最后一段
ech read ce57ce36
# 带上工具输出（每条前 2000 字）
ech read ce57ce36#21 --tools
# 续上一个会话：最近一次压缩的阶段总结和之后的全部对话，读完就能接着做
ech context ce57ce36
# 原会话的恢复命令：cd <文件夹> && claude --resume <完整 ID>（Codex 是 codex resume），用户贴到终端或 MintPop 主页
ech resume 9f4476a1
# 会话的分段：每段一个引用、起止时间、提交的版本、第一句话
ech segs ce57ce36
# 一周的会话：标题、项目、我的消息数、Token、提交次数和版本（日期含两头，北京时间）
ech list --since 2026-11-16 --until 2026-11-22
# 最近 7 天、只看项目路径里有 NAS 的
ech list --since 7d --project NAS
# 改文件夹名，本机的会话（Claude Code、Codex）随之移动；先 --dry-run 看会移动几个会话、哪些不移动
ech mv ~/伙伴云NAS/客户文档/示例客户/项目二期 ~/伙伴云NAS/客户文档/示例客户/"02 二期项目" --dry-run
ech mv ~/伙伴云NAS/客户文档/示例客户/项目二期 ~/伙伴云NAS/客户文档/示例客户/"02 二期项目"
# 备份并更新索引和总览数据
ech backup
# 某条命令的参数（JSON）
ech schema read
```

日期写 `2026-11-16`、`2026/11/16`、`11-16`（今年），或 `7d`（最近 7 天，含今天），按北京时间、含两头；「上周」「本周」先换算成具体日期再写；各命令加 `--json` 输出 JSON，给脚本用。

## 规则

- 引用照抄 find、segs、list 输出里的写法，不自己拼会话 ID。
- 一页最多 8000 字，结尾写了下一页的命令；先用 find、segs 缩小范围，再 read 需要的那段，不整篇翻。
- 输出第一行「索引更新于 …」早于要查的内容时，先 `ech backup`。
- 要原话用 `ech read`，不直接读 `~/.claude`、`~/.codex` 和回响备份目录里的 `.jsonl`。
- 给用户引用原话时写会话标题和日期。
- `ech mv` 先 `--dry-run`，把会移动几个会话、哪些不移动告诉用户；有会话正在进行时它整个不动，让用户结束那个会话再改。
- 命令找不到（command not found）：让用户打开回响，在设置「通用」的「命令行工具」一行点「安装」。
